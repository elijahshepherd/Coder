# Coder Desktop

Coder Desktop is an official Coder subproject.

Repository: [elijahshepherd/Coder-Desktop](https://github.com/elijahshepherd/Coder-Desktop)

## Stable purpose

Coder Desktop brings the Coder idea into a desktop-focused environment. It is meant to help users work with AI agents on their own computer for coding tasks, project work, and broader computer assistance.

At the ecosystem level, Coder Desktop represents one way to make local agent work practical. It gives Coder a place where the user, the project, the model choice, and the computer workflow can meet in a focused interface.

## How it fits into Coder

Coder is the umbrella project. Coder Desktop is one implementation inside that umbrella.

The central Coder repository explains the long-term project idea and points to official subprojects. The Coder Desktop repository owns the desktop app's source code, active documentation, setup details, releases, and implementation notes.

## What belongs in the Coder Desktop repository

Use the Coder Desktop repository for changing details such as:

- Installation and download instructions.
- Development setup.
- Current feature documentation.
- Release notes.
- Security notes specific to the desktop app.
- Screenshots and interface walkthroughs.
- Implementation architecture.

Those details can change as the desktop app evolves, so they should not be frozen in this central repository.

## What belongs here

This page should stay as the stable catalog entry for Coder Desktop. It should explain what the subproject is, why it exists, and where to find it without depending on a specific release or temporary feature list.

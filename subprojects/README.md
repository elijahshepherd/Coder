# Subprojects

This folder lists official Coder subprojects.

A subproject is a separate tool, app, interface, package, or repository that belongs to the Coder ecosystem. The central Coder repository explains the whole project family. Each subproject owns its own changing implementation details.

## Current official subprojects

- [Coder Desktop](coder-desktop.md)

Coder Desktop is the only official subproject listed right now.

## What each subproject page should include

Each subproject page should explain:

- The stable purpose of the subproject.
- How it fits into the Coder ecosystem.
- Where its source repository lives.
- Which details belong in the subproject repository instead of this central repository.

Each page should avoid details that are expected to change often, such as current version numbers, exact feature lists, release notes, or temporary implementation notes.

## Adding future subprojects

When a new official Coder subproject is created, add a new Markdown file in this folder and link it from this index. Keep the explanation stable and point readers to the subproject repository for active details.
